# 🎮 CS Quest — วิทยาการคำนวณ RPG Multiplayer

เกม RPG สำรวจความรู้วิทยาการคำนวณ ม.1 แบบ Multiplayer เล่นผ่านเว็บเบราว์เซอร์
ไม่ต้องลงทะเบียน ไม่ต้องติดตั้ง เพียงเปิดลิงก์แล้วเล่นได้เลย

---

## โครงสร้างโปรเจกต์

```
cs-quest/
├── server/
│   ├── package.json      ← dependencies ของ Node.js
│   └── server.js         ← WebSocket + Express server
├── client/
│   ├── index.html        ← ตัวเกมทั้งหมด (HTML + CSS + JS)
│   └── questions.js      ← คำถาม 4 ด่าน
└── render.yaml           ← config สำหรับ deploy บน Render.com
```

---

## วิธี Deploy บน Render.com (ฟรี)

### ขั้นตอนที่ 1 — อัพขึ้น GitHub

1. สมัคร/เข้าสู่ระบบ [github.com](https://github.com)
2. สร้าง Repository ใหม่ ตั้งชื่อ `cs-quest`
3. อัพโหลดไฟล์ทั้งหมดในโฟลเดอร์ `cs-quest/` ขึ้น GitHub
   - วิธีง่ายที่สุด: ลาก-วาง ทั้งโฟลเดอร์เข้าหน้า GitHub

### ขั้นตอนที่ 2 — Deploy บน Render.com

1. สมัคร/เข้าสู่ระบบ [render.com](https://render.com)
2. กด **"New +"** → เลือก **"Web Service"**
3. เชื่อมต่อกับ GitHub → เลือก repository `cs-quest`
4. ตั้งค่าดังนี้:
   | ช่อง | ค่า |
   |------|-----|
   | Name | cs-quest-game |
   | Region | Singapore (ใกล้ไทยที่สุด) |
   | Build Command | `cd server && npm install` |
   | Start Command | `cd server && node server.js` |
5. กด **"Create Web Service"**
6. รอ ~2 นาที จะได้ URL เช่น `https://cs-quest-game.onrender.com`

> ✅ แค่นี้เสร็จแล้ว! นักเรียนเปิด URL นั้นเลยได้เลย

## วิธีทดสอบบนเครื่องตัวเอง (Local)

```bash
# 1. ติดตั้ง Node.js จาก https://nodejs.org (ครั้งเดียว)

# 2. เปิด Terminal ไปที่โฟลเดอร์ server
cd cs-quest/server

# 3. ติดตั้ง dependencies
npm install

# 4. รัน server
node server.js

# 5. เปิดเบราว์เซอร์ไปที่
# http://localhost:3000
```

## วิธีเล่นเกม

| ปุ่ม | การกระทำ |
|------|----------|
| WASD หรือ ลูกศร | เดินตัวละคร |
| Space หรือ E | คุยกับ NPC (เมื่อเดินเข้าใกล้) |
| Enter | เปิด/ส่งข้อความแชท |
| Escape | ปิด dialog |
| มือถือ | ใช้ joystick ซ้ายล่าง + แตะหน้าจอเพื่อคุย NPC |

### ขั้นตอนการเล่น

1. กรอกชื่อ → เลือกตัวละคร → เลือกด่าน → กรอกรหัสห้อง (ถ้าอยากเล่นกับเพื่อน)
2. เดินสำรวจแผนที่ หา NPC (มีเครื่องหมาย `!` สีเหลืองเหนือหัว)
3. เดินเข้าใกล้ NPC แล้วกด Space/E เพื่อรับคำถาม
4. ตอบถูก = +100 คะแนน | ตอบครบทุก NPC = ผ่านด่าน
5. ดูอันดับ Leaderboard ด้านขวาบน

## รองรับผู้เล่นสูงสุด 30 คน/ห้อง

- แต่ละห้องรองรับได้ 30 คนพร้อมกัน
- สร้างห้องหลายห้องได้ไม่จำกัด (ใช้รหัสห้องแตกต่างกัน)
- ตัวอย่าง: ห้อง 101 ใช้รหัส `m1-101`, ห้อง 102 ใช้ `m1-102`

## วิธีเพิ่ม/แก้ไขคำถาม

แก้ไขไฟล์ `client/questions.js`

```javascript
// ตัวอย่างการเพิ่มคำถาม
{
  q: 'คำถามของคุณ?',
  opts: ['ตัวเลือก ก', 'ตัวเลือก ข', 'ตัวเลือก ค', 'ตัวเลือก ง'],
  ans: 0,  // index ของคำตอบที่ถูก (0=ก, 1=ข, 2=ค, 3=ง)
  explain: 'คำอธิบายเฉลย'
}
```

## หมายเหตุสำหรับครู

- **Render.com ฟรีแพลน**: server จะ "หลับ" หากไม่มีคนใช้นาน 15 นาที
  ครั้งแรกที่เปิดอาจรอ 30-60 วินาที (warm up)
- แนะนำให้ครูเปิดหน้าเว็บไว้ก่อนเริ่มชั่วโมงเรียน เพื่อให้ server ตื่น
- หากต้องการ server ที่เร็วตลอดเวลา พิจารณาแพลน Starter $7/เดือน
